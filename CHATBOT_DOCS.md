## 🔧 Personalização

### Adicionar Nova Resposta:

```tsx
// No método getBotResponse:
if (msg.includes("sua palavra-chave")) {
  return "Sua resposta aqui! 😊";
}
```

### Adicionar Quick Reply:

```tsx
{ 
  text: "Texto do botão", 
  response: "Resposta do bot" 
}
```

### Mudar Cores:

```tsx
// Header
className="bg-gradient-to-r from-primary to-accent"

// Botão flutuante
className="bg-gradient-to-r from-primary to-accent"
```
